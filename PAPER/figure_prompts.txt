General instructions for ALL figures:
- Style: scientific, publication-quality, white background
- Font: sans-serif (e.g., Helvetica or similar), minimum 10pt labels
- Resolution: 300 DPI minimum for print; export as PNG or PDF
- Colour palette: accessible, distinct colours (avoid red/green alone for
  colour-blind readers — add shape/pattern coding where possible)
- No decorative borders, no 3-D effects, no clip art
- Each figure should be self-explanatory from its caption alone
- Dimensions: target ~90 mm (single column) or ~190 mm (double column) wide

--------------------------------------------------------------------------------
HOW TO USE THE "LATEX TO PASTE" BLOCKS
--------------------------------------------------------------------------------
After generating each figure with Gemini:
1. Save the image into a  figures/  subfolder next to sea_ice_paper.tex, using
   the exact filename given in each LaTeX block (e.g. figures/architecture.png).
2. In sea_ice_paper.tex, find the matching placeholder — the block that reads
   \begin{figure}...\fbox{...[FIGURE PLACEHOLDER — fig:xxx]...}...\end{figure}
   — and REPLACE the entire placeholder block with the "LATEX TO PASTE" code below.
3. The preamble already loads \usepackage{graphicx}. Optionally add this line
   once, just after the other \usepackage lines, so you can drop the "figures/"
   prefix from every path:
       \graphicspath{{figures/}}
4. Single-column figures use \begin{figure} (width=\linewidth); full-width
   figures use \begin{figure*} (width=\textwidth) so they span both columns.
   Captions/labels below match the paper exactly — do not change the \label.
